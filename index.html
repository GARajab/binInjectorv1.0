How to Use This PC Proxy:

  1. Prerequisites:
    • PS4 must be jailbroken with BinLoader installed
    • PS4 and PC must be on the same network
    • BinLoader server must be running on PS4 (port 9090 by default)
  2. Setup:
    • Enter your PS4's IP address (find it in PS4 network settings)
    • Click "Test Connection" to verify BinLoader is reachable
  3. Injection:
    • Click "Select .bin File" to choose a payload from your PC
    • Click "Inject Payload" to send it to your PS4
  4. Troubleshooting:
    • Make sure BinLoader is running on PS4 (http://PS4_IP:9090)
    • Check firewall settings on both PC and router
    • Try using the PS4's browser directly if this doesn't work
